## 1. Сводка

**Сильные стороны:**
- Чистое разделение слоёв: `config` (данные) → `models` (домен) → `game_controller` (логика, без Textual) → `galaxy_map`/`ui` (презентация). Именно поэтому 848 тестов гоняются headless.
- Мир тикает только по вводу игрока — таймеров нет, гонок нет.
- Конфиг-словари (оружие, ресурсы, враги, здания, рецепты) — декларативные; добавление новой сущности часто = запись в словарь.

- Локализация: паритет ключей RU/EN 100%, плейсхолдеры совпадают 0/0 расхождений.

**Главные проблемы:**
- P0-класс: ~8 багов уровня «краш / потеря прогресса / механика вообще не работает» (раздел 7).
- Боевой лог не локализован (53 англ. строки при 38 готовых переводах).
- Покрытие тестами ~50%; ui.py — 10%; ~20 пустых/тавтологических тестов; 3 сломанные фикстуры conftest.
- README обещает механики, которых нет в коде (кража груза пиратами, иммунитет Voidborn, авто-ремонт Machine Cult).
- Save только в памяти (pickle в bytes), `autosave` — мёртвый переключатель.

## 2. Архитектура

### Сильное
- `GalaxyMapApp` — тонкая оболочка: делегирует всю логику через property-шорткаты (`galaxy_map.py:64-232`); `GameController` свободен от Textual.
- Заморозка мира при открытии экранов через переопределённый `push_screen` (`galaxy_map.py:288-290`) + `on_screen_resume` (`galaxy_map.py:292-294`) + guard `if len(self.screen_stack) > 1: return` (`galaxy_map.py:310-312`).
- `BaseScreen.dismiss_and_push` (`ui.py:46-52`) — правильный паттерн, но используется только в одном экране.

### Проблемы

| № | Проблема | Где | Почему плохо |

## 3. Механики — подтверждённые баги

> Помечено ✅ — проверено запуском кода. Остальное — подтверждено чтением кода + агентами (file:line).

### 3.1 Мир / генерация

1. ✅ **Торговцы застревают у первой станции навсегда** (`models.py`): `_occupied` (`:2236`) запрещает клетку станции, условие прибытия `t.x == tg.x and t.y == tg.y` (`:2162`) никогда не срабатывает → `wait_ticks`/смена маршрута — мёртвый код (симуляция 200 тиков: `route_index` не меняется). README обещает «traders follow trade routes».
   **Фикс:** прибытие = «рядом со станцией» (Chebyshev ≤ 1).
2. ✅ **ORIGINS ссылаются на несуществующие корпуса**: `trader → "freighter"`, `explorer → "scout"` нет в `SHIP_HULLS` → `select_origin` молча оставляет corvette. Груз `"food"` (explorer) не в `RESOURCES` — мёртвый груз; `"slug"` (imperial_officer) — аммо, не торгуется («Unknown 'slug'.»).
3. **Высадка на астероид невозможна**: `TILE_TO_SITE` использует `"÷"` вместо `"░"` (`TILE_ASTEROIDS`) и `"◈"` вместо `"☐"` (`TILE_STATION`) (`game_controller.py:1109, 1164`) — ветка недостижима.
4. **Ремонт на станции капает корпус на 100**: `max_hull = 100 + hull_bonus` хардкод (`game_controller.py:985`) — фрегат (160) нельзя отремонтировать выше 100.
5. ✅ **Расходники сжигаются впустую**: `use_item` списывает предмет до расчёта эффекта — repair_kit при полном корпусе даёт «Restored 0 hull», shield_booster при `shield_cap=0` даёт «Boosted -30 shields» (`models.py:819-848`; то же в бою `battle.py:601-624`).
   **Фикс:** проверять фактический эффект до списания.
6. **README ≠ код**: нет кражи груза пиратами, иммунитета Voidborn к гравитации, авто-ремонта Machine Cult, бонуса Xenos Bio к органике, стартовой вражды к Voidborn.
7. **Червоточины, дипломатия, глобальный кризис не тикают**: `Galaxy.tick` (`models.py:2110-2146`) обрабатывает только ЧД/радиацию/астероиды/экономику/колонии; `events_queue`, `global_crisis_ticks`, `diplomacy` — декорация. Заявленной «нестабильности червоточин» нет.
8. **Гравитация ЧД может затянуть на тайл звезды** (нет проверки `is_passable` в пуле, `models.py:2117-2129`); при этом стоять на звезде безопасно — радиация исключает собственную клетку (`:2132`).
9. **Консоль падает на нечисловом вводе**: `give metal abc`, `set hull x`, `trade buy ore x` → `ValueError` (`game_controller.py:1287-1430`, `int()` без try).
   **Фикс:** обёртка int с обработкой ошибки.
10. **Побег пирата работает только по X** (`models.py:2227-2230`): при одинаковой X с игроком (`dx=0`) пират не отступает.
11. **Детерминизм генерации нарушен**: `Galaxy` использует свой `Random(seed)`, но `random_planet_type()` (colony) и расы CrewMember — глобальный `random` → сид не воспроизводим.
12. `Galaxy._nearby()` клампит к константам WIDTH/HEIGHT (80×40), а не к `self.width/height` — кастомные размеры карты ломаются (см. фикстуру galaxy, раздел 6).

## 8. Отмечено как НЕ баг (проверено, снято с отчёта)

- **Отрицательные суммы в трансферах колоний** — на уровне API (`colony.transfer_to_ship/from_ship`) суммы защищены (возврат 0, изменений нет); эксплойт возможен только если UI пропустит отрицательное значение — в текущем коде колониальный API безопасен.
- **Дублирование ID миссий после save/restore** — счётчик `Mission._id_counter` не восстанавливается, но коллизий не возникает (новые миссии получают большие ID).
- **Слияние настроек** (`load_settings`) — топ-уровневое слияние с дефолтами корректно; частичный вложенный `keys` ломается только при ручной правке файла.
